3 대시보드
로그인 후 기본 진입 화면. API: GET /api/admin/dashboard
  • 📊
    KPI 카드 3개

    누적 고객 수 / 전체 컨설턴트 수 / 활성 컨설턴트 수 — 실시간 DB 카운트

  • 📋
    최근 접수 10건

    고객명, BC코드(컬러 배지), 담당 컨설턴트, 접수 일시 테이블. 결과지 링크 버튼 포함.

  • 🧬
    BC코드 분포 차트

    전체 고객의 BC코드별 비율. 각 코드의 컬러로 시각화된 바 차트.

4 컨설턴트 관리
컨설턴트 계정 전체 CRUD. 검색·필터·등록·수정·정지·삭제.
  • 🔍
    검색 + 상태 필터

    이름/코드/이메일 통합 검색. 활성/대기/정지/만료 상태별 필터.

  • ➕
    신규 컨설턴트 등록 모달

    이름·이메일·전화번호·직종(트레이너/필라테스/뷰티/병원직원/영양사)·등급(일반/시니어/마스터)·구독만료일·메모 입력.
    코드 자동 생성 SC-0001 또는 커스텀 코드 지정 가능.
    초기 비밀번호 자동 생성 또는 직접 지정. 랜덤 생성 버튼 제공.

  • ✅
    등록 완료 팝업 — 전달 안내문 자동 생성

    등록 후 컨설턴트 코드·비밀번호·설문링크·대시보드 링크가 담긴 안내문 자동 생성. 전체 복사 버튼 1클릭으로 카카오 전달 가능.

  • ✏️
    수정

    이름·직종·등급·구독만료일·강의진도·자격증여부·메모 수정 가능.

  • 🚫
    정지 (소프트 삭제)

    계정만 비활성화. 고객 데이터는 보존됨. 재활성화 가능.

  • 🗑️
    영구 삭제 (하드 삭제)

    컨설턴트 + 관련 고객 결과지까지 완전 삭제. 이중 확인 팝업 필수.

  • 🔁
    대리 접속 (Impersonate)

    마스터가 특정 컨설턴트의 계정으로 로그인 전환 → 컨설턴트 화면 그대로 확인 가능.

5 B2B 파트너 관리
제휴 업체 계정 생성·수정·화이트라벨 브랜딩 설정.
  • 🎨
    화이트라벨 브랜딩 설정

    브랜드명, 브랜드 컬러(컬러피커 + HEX 입력 + 실시간 미리보기), 로고 이미지 URL.
    설정 후 파트너 전용 URL(/s/B2B-XXX-001)로 접속하면 해당 업체 브랜드로 설문 화면 자동 변경.

  • 🏢
    업체 정보 입력

    영업장명, 업종(에스테틱/필라테스/한의원/헬스장/뷰티숍/병원/기타), 원장명, 연락처, 이메일, 주소, 수수료율(%).

  • 🔑
    자동 코드 발급

    업종 기반 코드 자동 생성 (B2B-AES-001) 또는 커스텀 코드 지정. 초기 비밀번호 자동/직접 설정.

  • ✅
    등록 완료 팝업

    파트너 코드·비밀번호·고객 설문 링크·B2B 대시보드 링크 즉시 표시 + 전체 복사.

6 고객 결과 관리
전체 고객 결과지 조회·검색·필터. API: GET /api/admin/results
  • 🔍
    3중 필터

    이름/ID 텍스트 검색 + BC코드별 필터 + 담당 컨설턴트별 필터 동시 적용 가능. 최대 100건 표시.

  • 🔗
    결과지 링크

    각 행에서 /result/RES-xxx 공유 링크 바로 열기.

7 BC코드 처방 편집기
BC-01~22 전체 처방 데이터를 관리자 화면에서 직접 편집. API: GET/PUT /api/admin/bc-codes
  • 📑
    4탭 편집기

    기본 정보 브랜드명, 태그라인, 지방 부위, 한 줄 원인, 원인 스토리, 악화 단어, 마감 카피, 증상 체크리스트
    운동 처방 Zone2 심박수, 금지 심박수, HIIT 시작 주차, 추천/금지 운동 JSON
    식단 처방 추천 식품, 금지 식품, 영양제 목록 JSON
    생활 습관 생활 규칙, 올바른 원칙, 잘못된 방법, 월별 목표, 변경 메모

8 컨설턴트 랭킹
기간별 실적 순위. API: GET /api/admin/ranking?period=month|quarter
  • 🏆
    이달 / 분기 전환

    탭 전환으로 이번 달 또는 이번 분기 기준 집계.

  • 📊
    전월 대비 성장률 자동 계산

    전월 실적과 비교하여 성장률(%) 자동 계산. 증가 시 🟢 감소 시 🔴 표시.

  • 👑
    MVP 강조 표시

    1위 컨설턴트 왕관 아이콘 + 강조 배경 표시. 예상 정산금 함께 표시.

9 매출 예측기
이번 달 추이 기반 월말 예상 매출 자동 산출. API: GET /api/admin/revenue-forecast
  • 📈
    선형 추세 예측 엔진

    오늘까지의 일별 데이터 기반 → 남은 일수 예측 → 월말 예상 건수·매출 자동 계산. 엑셀 작업 불필요.

  • 💰
    매출·정산 동시 표시

    예상 매출(건당 150,000원 기준)과 예상 정산금(25%)을 함께 표시.

10 수익 정산
월별 컨설턴트별 정산 자동 산출. API: GET /api/admin/settlement?month=YYYY-MM
  • 🗓️
    월 선택기

    월 선택 드롭다운 → 해당 월 컨설턴트별 건수·매출·정산금(25%) 자동 집계 테이블.

  • 📋
    총합 요약

    전체 건수·총 매출·총 정산금 합계 헤더 카드로 표시.

11 월간 AI 리포트
이달 전체 운영 현황 종합 분석. API: GET /api/admin/monthly-report
  • 📊
    6가지 지표 자동 수집

    이달 신규 고객 수 / 전월 대비 성장률 / 활성 컨설턴트 수 / 이달 체크인 수 / 이탈 위험 고객(21일 이상 미방문) / 컨설턴트 TOP 5 실적

  • 📅
    6개월 트렌드

    최근 6개월 월별 신규 고객 추이 바 차트.

12 엑셀 다운로드
전체 고객 데이터 CSV 내보내기.
  • 📥
    고객 전체 CSV 다운로드

    ID, 이름, BC코드, 담당 컨설턴트, 접수일 등 주요 컬럼 포함. 브라우저 직접 다운로드.

13 카카오 설정
카카오 알림톡 API 키 관리. API: GET/PUT /api/settings/kakao
  • 💛
    카카오 앱 키 등록

    카카오 API 키 입력·저장. 키 없어도 클립보드 복사 방식으로 수동 발송 가능.
