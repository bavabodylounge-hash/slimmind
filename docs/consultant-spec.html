3 대시보드 탭
로그인 후 기본 화면. 내 실적과 최근 고객을 한눈에.
  • 📊
    내 실적 KPI 카드

    이달 상담 건수 / 누적 고객 수 / 최근 7일 신규 고객 수. API: GET /api/consultant/stats

  • 📋
    최근 접수 고객 목록

    내가 담당한 최근 고객 8명. 이름·BC코드·접수일·결과지 링크.

  • 🧬
    내 고객 BC코드 분포

    내 고객들의 BC코드 비율 시각화. 어떤 유형이 많은지 파악 가능.

4 내 고객 목록 탭
담당 고객 전체 조회 및 개별 관리. API: GET /api/consultant/results
  • 🔍
    이름 검색 + BC코드 필터

    고객 이름 검색 및 BC코드별 필터. 내 담당 고객만 표시.

  • 📝
    메모 추가

    각 고객에게 상담 메모 작성 가능. API: PUT /api/results/:id/memo

  • 📤
    카카오 결과 공유

    결과지 URL + 고객명 + BC코드가 포함된 카카오 메시지 자동 생성. 클립보드 복사 후 카카오 전송.

  • 🔗
    결과지 링크

    /result/RES-xxx 공유 링크 클릭 → result-v4.html 최신 결과지 열림.

  • 📊
    체크인 현황 표시

    각 고객의 마지막 체크인 일자 + 총 체크인 횟수 표시. 관리 필요 고객 파악 가능.

5 초대 링크 탭
고객 유입을 위한 고유 설문 링크 + QR코드 관리.
  • 🔗
    고유 설문 URL

    https://도메인/s/SC-0001 형식. 이 링크로 접속한 고객은 자동으로 내 담당으로 등록됨.

  • 📱
    QR코드 즉시 생성

    URL 기반 QR코드 자동 생성. 인쇄 버튼으로 바로 인쇄 가능. 상담 현장 비치용.

  • 📋
    링크 복사 버튼

    1클릭으로 클립보드 복사 → 카카오·문자로 즉시 공유 가능.

6 AI 상담 멘트 탭 ⭐ 핵심 기능
BC코드 선택 → 고객 이름 입력 → 1클릭으로 5종류 상담 멘트 자동 생성. API: POST /api/consultant/ai-message
  • 🎯
    BC코드 선택 드롭다운 (BC-01~22 전체)

    체형·지방 유형(BC-01~10) / 기능·대사·피부 유형(BC-11~22) 두 그룹으로 구분된 옵션 선택.

  • ⚡
    최근 고객 빠른 선택 버튼

    최근 8명의 고객이 버튼으로 표시됨. 클릭 한 번으로 이름·BC코드 자동 입력 후 즉시 생성.

  • 🤖
    5종류 멘트 자동 생성

    BC코드 처방 DB에서 브랜드명·원인스토리·처방원칙·생활규칙을 가져와 개인화된 멘트 구성.

생성되는 5가지 멘트 유형:
👋 초진 환영 멘트
"[고객명]님, 슬림마인드에 오신 걸 환영합니다! 체형 분석 결과 [고객명]님의 유형은 [브랜드명]입니다. [한줄원인] 지금부터 [고객명]님만을 위한 맞춤 처방을 시작해드릴게요."
🔍 원인 설명 멘트
"[고객명]님, 지금까지 다이어트가 어려우셨던 건 의지 부족이 아니에요. [원인 스토리] 원인을 알면 해결책도 명확해집니다."
💊 처방 안내 멘트
"[고객명]님의 [브랜드명] 유형에는 [처방원칙1], [처방원칙2] 접근이 핵심입니다. 일상에서는 [생활규칙]을 꼭 지켜주세요."
💪 동기부여 멘트
"[고객명]님, [마감 카피] 저희가 끝까지 함께하겠습니다. 오늘 첫 걸음이 가장 중요한 걸음입니다!"
📅 재방문 독려 멘트
"[고객명]님, 오늘 상담 잘 마무리하셨나요? [브랜드명] 유형은 꾸준한 관리가 특히 중요합니다. 다음 방문까지 [생활규칙]을 실천해보시고..."
💡 사용법: 각 멘트 카드를 클릭하면 클립보드에 자동 복사 → 카카오톡에 바로 붙여넣기 가능.
7 체중 추적 탭
고객별 주차 체중 기록 및 변화 그래프 확인.
  • 📋
    내 고객 목록에서 고객 선택

    API: GET /api/consultant/my-customers — 체크인 횟수와 마지막 체크인 일자 함께 표시.

  • ⚖️
    주차별 체중 체크인 기록

    고객 선택 → 주차 + 현재 체중(kg) + 메모 입력 → 저장. API: POST /api/consultant/weight-checkin

  • 📈
    체중 변화 그래프

    체크인 기록 기반 꺾은선 그래프 시각화. 목표 체중 라인 함께 표시. API: GET /api/consultant/checkin-history/:result_id

8 내 정보 탭
프로필 확인 및 비밀번호 변경.
  • 👤
    프로필 정보 확인

    내 코드, 이름, 등급, 구독 상태, 구독 만료일, 이메일, 전화번호. API: GET /api/consultant/me

  • 🔒
    비밀번호 변경

    현재 비밀번호 확인 → 새 비밀번호 입력 → 변경. API: PUT /api/consultant/change-password

9 바디코드 도감 탭
BC-01~22 처방 정보 열람. 상담 전 준비 자료.
  • 🧬
    22개 BC코드 카드 뷰

    각 코드별 컬러·아이콘·브랜드명·태그라인 표시. 클릭 시 전체 처방 상세 열람 가능.

  • 📋
    처방 상세 정보

    원인 스토리·추천 식품·금지 식품·운동 처방·영양제·생활 규칙·월간 목표 전체 열람.
