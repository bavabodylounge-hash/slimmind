3 화이트라벨 브랜딩 시스템
파트너 전용 URL로 접속 시 해당 업체 브랜드가 설문지에 자동 적용됨.
  • 🔗
    파트너 전용 URL

    https://도메인/s/B2B-AES-001 → API에서 브랜드 데이터 조회 → 설문지에 자동 주입

  • 🎨
    브랜드 컬러 적용

    설문지 버튼·진행 바·포인트 컬러가 파트너 브랜드 컬러(HEX)로 자동 변경.

  • 🖼️
    로고 표시

    등록된 로고 URL이 설문지 상단에 표시됨. 고객은 파트너 업체 서비스처럼 인식.

  • 📊
    스캔 카운트 자동 추적

    파트너 URL 접속 시 scan_count 자동 증가. 대시보드에서 유입 수 확인 가능.

B2B-AES-001 (아라 에스테틱) 브랜드 예시
아라 체형 분석 시작하기 →
설문지 상단에 로고 + 브랜드컬러 버튼 자동 적용
4 대시보드
파트너 운영 현황 한눈에 확인. API: GET /api/b2b/stats
  • 📊
    핵심 KPI 카드

    총 방문 고객 수 / 이달 신규 고객 수 / QR 스캔 총 수 / 활성 직원 수

  • 🧬
    우리 업체 BC코드 분포

    소속 고객들의 BC코드 비율. 어떤 유형 고객이 많이 오는지 파악 가능.

  • 📋
    최근 접수 고객 5명

    이름, BC코드, 접수일 표시. 결과지 바로 열기.

5 고객 결과 조회
파트너 코드(ref_code)로 등록된 고객만 조회 가능. API: GET /api/b2b/results
  • 🔍
    이름 검색 + BC코드 필터

    고객 이름 일부 검색. BC코드별 필터. 소속 고객만 표시됨.

  • ⚡
    고객 이름 즉시 검색 (상담 중 활용)

    API: GET /api/b2b/customer-lookup?name=xxx — 이름으로 BC코드 + 처방 핵심 내용 즉시 조회. 상담 중 빠른 확인 용도.

  • 🔗
    결과지 공유 링크 발급

    API: GET /api/b2b/result-link/:id — 해당 고객이 내 소속인지 확인 후 결과지 URL 반환. 권한 없는 결과지 접근 차단.

6 파트너 추천 뷰 ⭐ 핵심 기능
BC코드별 처방 정보 + 업체 등록 시술 자동 매칭 추천. API: GET /api/b2b/partner-view/:bc_code + GET /api/b2b/recommend/:resultId
  • 🧬
    22개 BC코드 버튼 선택

    BC-01~22 전체 버튼. 컬러·아이콘 표시. 클릭 시 해당 BC코드 처방 전체 표시.

  • 📋
    처방 상세 표시

    브랜드명·원인 스토리·추천 식품·금지 식품·추천 운동·금지 운동·영양제·생활 규칙·월간 목표 전체 표시.

  • 💊
    시술 자동 추천 패널

    고객 BC코드 → 파트너가 등록한 시술 프로그램 중 bc_tags에 해당 코드가 포함된 것 자동 필터링.
    추천 코멘트(BC코드별 맞춤 멘트) + 매칭 시술 목록 + 가격순 정렬.

추천 흐름 예시:
고객 BC코드: BC-05 (하체비만형) → 파트너 시술 중 bc_tags에 'BC-05' 포함된 시술 자동 추출 →
"하체·허벅지 라인 슬리밍 — 허벅지·종아리 부위에 카복시·윤곽주사·바디보톡스가 효과적입니다." + 매칭 시술 리스트 표시
7 QR 코드 출력
파트너 전용 QR코드 생성 및 인쇄용 출력.
  • 📱
    브랜드 컬러 QR코드

    파트너 전용 URL(/s/B2B-xxx-001) 기반 QR코드 자동 생성.

  • 🖨️
    인쇄 최적화 출력

    A4·명함·스티커 크기 선택 → 브라우저 인쇄 다이얼로그 바로 호출. 업체 현장 비치용.

8 직원 계정 관리 (서브계정)
원장 계정이 직원 서브계정 생성·관리. API: GET/POST/DELETE /api/b2b/subaccounts
  • ➕
    직원 서브계정 생성

    직원 이름·이메일·전화번호 입력 → 서브계정 코드 자동 발급 (B2B-xxx-001-01 형식).
    같은 파트너 그룹으로 고객 데이터 공유됨.

  • 🗑️
    직원 계정 삭제

    직원 퇴사 시 계정 삭제. 해당 직원이 기록한 고객 데이터는 파트너 계정으로 귀속됨.

13 B2B SaaS 비즈니스 모델 구조
슬림마인드의 B2B 확장 방향.
  • 💰
    파트너 월정액 수익 모델

    각 파트너에 독립된 브랜드·데이터·계정 구조. 파트너당 월정액 요금으로 SaaS 전환 가능.

  • 📊
    수수료 기반 정산

    파트너별 commission_rate 설정 (기본 15%). 고객 프로그램 매출에서 수수료 자동 산출.

  • 🔗
    시술 추천 → 매출 연결

    고객 BC코드 → 파트너 시술 자동 추천 → 상담사가 즉시 제안 → 매출 증대. 경험 없어도 적절한 시술 추천 가능.

  • 🏪
    대상 업종

    에스테틱, 필라테스, 한의원, 헬스장, 뷰티숍, 병원 — 체형·미용 관련 B2B 파트너 전방위 확장 가능.
