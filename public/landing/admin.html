👥 회원 데이터 백업 (users)
전체 회원 데이터 (이름, 이메일, 전화번호, 회원유형, 가입경로, 가입일, 접속IP)를 내보냅니다.
DB 스키마: id, name, email, phone, member_type, provider, created_at, last_login_ip
🧪 파일럿 신청 데이터 백업 (pilot_requests)
파일럿 무료 체험 신청 내역 (기관명, 담당자, 유형, 연락처, 신청일, 상담상태, 메모)을 내보냅니다.
DB 스키마: id, organization_name, contact_name, member_type, phone, email, status, memo, created_at, updated_at
🎓 컨설턴트 신청 데이터 백업 (consultant_applies)
바디컨설턴트 지원 내역 (신청자 정보, 전문분야, 경력, 심사상태)을 내보냅니다.
DB 스키마: id, user_id, specialty, experience_years, background, status, admin_memo, created_at, updated_at
🗃️ 전체 DB 풀 백업
users + pilot_requests + consultant_applies 전체 테이블 합본 백업입니다. 정기 백업에 사용하세요.
